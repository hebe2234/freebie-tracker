## 功能 Features
- **流量統計**：已埋 Google Analytics 程式碼。去 https://analytics.google.com 建 GA4 資源，把 `index.html` 最上方的 `GA_ID = "G-XXXXXXX"` 換成你的評估 ID 後重新上傳，全站流量＋每個連結的點擊（事件 `outbound_click`）就會出現在 GA 後台。
- **用戶回報**：每張卡片的「💬 回報」鈕會開 GitHub issue（標題自動帶項目名稱），回報集中在 repo 的 Issues 分頁。
- **點擊率**：卡片上的 👆 數字是「這台裝置」的本機統計；真實全站數據看 GA4 後台。
